# AI 小石头

首页入口进入的应用内业务向导助手：气泡多轮对话，助手回复经 SSE 流式展示。会话仅在当次停留页内有效。

## Language

**AI 小石头（Little Stone）**:
面向本 App / 4S 店场景的业务向导助手品牌名；回答应用内如何使用各能力，不是通用闲聊机器人，也不是真人销售客服。
_Avoid_: 客户管理、智能客服（作产品名时）、ChatGPT、销冠

**停留会话（Visit Conversation）**:
用户一次进入助手页到离开该页之间的对话容器；由服务端在用户首句开口时创建并下发 `conversationId`，离开页面即丢弃，不提供跨次打开的续聊。服务端在约 30 分钟无活动后也不再认可该会话（活动可续期）。
_Avoid_: 长期会话、聊天记录、IM 会话、融云会话

**快捷问（Quick Prompt）**:
页面上由客户端配置的固定芯片文案；点击后作为一条用户消息发送。不是助手回复里的跳转按钮。
_Avoid_: 动作卡片、深链按钮、推荐工具

**流式回复（Streamed Reply）**:
助手针对一轮用户消息、经 SSE 增量到达并在气泡中逐步显现的纯文本；一期不做 Markdown 渲染。
_Avoid_: 整包 JSON 答完再显示、IM 推送消息、流式 Markdown

**停止生成（Stop Generation）**:
用户在流式回复尚未结束时主动取消当轮 SSE；已显示的文字保留在气泡中，用户可继续发送下一句。
_Avoid_: 退出页面才断开、重新生成

**单轮在途（Single In-Flight）**:
同一停留会话内同一时刻最多只有一轮流式回复在进行；流式期间不可发送下一条，只能停止或等待结束。
_Avoid_: 发送即取消当前流、多气泡并行生成

**上下文窗口（Context Window）**:
服务端为生成下一句流式回复所使用的最近对话轮次上限（默认 10 轮）；与页面上可见的气泡条数无关。
_Avoid_: 全量历史、聊天记录归档
