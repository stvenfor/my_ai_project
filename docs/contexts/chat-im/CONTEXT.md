# Chat IM（融云）

App「聊天」Tab 与即时消息语境：真人/群之间的会话，经融云 IM 通道，与 Realtime 通知、AI 小石头 SSE 停留会话分离。

## Language

**融云 IM (RongCloud IM)**：
聊天 Tab 的即时消息通道；消息由客户端 SDK 直连融云收发。不是系统通知通道，也不是 AI 助手生成流。
_Avoid_: Realtime WS、SSE 停留会话、把助手气泡写入融云

**单聊 (Private Chat)**：
两名业务用户之间的一对一会话。
_Avoid_: 群聊、聊天室、超级群

**群聊 (Group Chat)**：
多名业务用户共用的群组会话（融云「群组」，非超级群/聊天室）。
_Avoid_: 超级群、聊天室、门店统计卡

**融云用户标识 (RongCloud User Id)**：
连接融云时使用的用户 ID；与业务用户 UUID 同一值。
_Avoid_: 本地 `im_u_*` 映射、另造一套 IM 账号

**IM 连接凭证 (IM Token)**：
服务端签发、客户端用来连接融云的短期凭证。不是业务登录 access token。
_Avoid_: 业务 JWT、在客户端用 App Secret 自签

**好友 (Friend)**：
双向确认后的人际关系；双方同意后才可从好友入口发起单聊。应用层关系，非融云内置。
_Avoid_: 单向关注即可聊、把门店成员自动当好友、把「能搜到用户」等同于好友

**好友申请 (Friend Request)**：
一方向另一方发出的加好友请求；对方同意后双方成为好友，拒绝或忽略则不成。
_Avoid_: 静默互加、无需同意的通讯录

**门店群 (Store Group)**：
与某一家门店绑定、由 BFF 保证存在的群聊；门店成员入店后被拉入该群。一店至多一群。
_Avoid_: 与门店无关的自由群当门店群、把门店成员名单当成会话列表、每店多群（本期）

**自由群 (Free Group)**：
用户主动创建、与门店无绑定的群聊。创建者为群主：仅群主可邀请、踢人、解散；成员可自行退群。与门店群并存。
_Avoid_: 把门店自动群叫做自由群、用自由群替代一店一群、全员可踢人/解散

**消息业务备份 (IM Message Backup)**：
在融云历史之外，把收/发/撤回事件异步写入本业务库，供检索与合规。不是融云云端历史本身。与好友能力同一交付阶段上线。
_Avoid_: 只靠融云历史当业务库、在聊天热路径同步阻塞写库、把 AI SSE 气泡写入备份、把备份拖到门店群之后才做

**单聊准入 (Private Chat Admission)**：
发起或进入单聊前，双方须已是好友。门店群/自由群内的群消息不要求互为好友。
_Avoid_: 任意 UUID 直开单聊、把门店同事默认可单聊（除非先加好友）
